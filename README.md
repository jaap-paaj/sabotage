# Sabotage

Sample-trigger met tap tempo voor live gebruik. Open de app op
https://jaap-paaj.github.io/sabotage/ en zet hem op je beginscherm.

## Ingebouwd geluid

`scratch.wav` is een synthetisch geluid: een scratch-loopje van vijf halen op
achtste noten (168 BPM). De toonhoogtelijnen zijn gemeten met
`tools/resynth.js` en daarna opnieuw opgebouwd uit sinustonen; er zit geen
opgenomen audio in.
